# AeroGuard AI

## AI-Powered Predictive Maintenance System

AeroGuard AI is an end-to-end Machine Learning project
for estimating the Remaining Useful Life (RUL) of
simulated turbofan engines.

## Dataset
NASA C-MAPSS (FD001)

## Technologies
- Python
- NumPy and Pandas
- Scikit-learn
- Matplotlib and Seaborn
- XGBoost (planned)
- FastAPI (planned)
- React, Node.js, Express, MongoDB (planned)

## Project Status
Phase 1: Environment setup and dataset exploration.

## Development Roadmap
1. Data exploration and validation
2. Feature engineering
3. ML training and evaluation
4. FastAPI inference service
5. MERN dashboard
6. Testing and deployment

## Dataset Source
https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/

## Disclaimer
This project uses simulated engine data for
research and demonstration purposes.
